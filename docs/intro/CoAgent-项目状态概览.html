02 产品定位

CoAgent 面向 Agent 上线之后的运行态运维：在事故发生时给出可解释的根因假设、把握度评分与分级处置建议， 让值班人敢于拍板「动还是不动」。当前版本提供处置建议、人工审批与模拟验证，不声称自动修复生产系统。

三类事故切面

  • S1 运行失败 — 客服限流 · 🟢 可重试
  • S2 质量异常 — RAG 空检索 · 🟡 需确认
  • S3 成本失控 — Token 超预算 · 🔴 升级

目标用户

  • Agent 交付 / FDE — 配手册与评分规则
  • 平台 SRE / 值班 — 诊断与分级处置
  • 客户 IT — 依据审计链安全拍板

赛道背景

  • 赛事 — 微软孵化器 × 小宿科技黑客松
  • 赛道 — ToB AI Agent
  • 许可证 — MIT
